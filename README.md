# UltimeClaim_IBNR_Calculator

Created a tool that calculates both the Ultimate Expected Claims and the IBNR Reserve as per the company size (Small , Medium, Large) and claim Type (Dental, Prescription, Healthcare Appointment) , with the use of Completion factors . 

Made use of Excel SUM functions , Vlookup , absolute and relative cell referencing and some cell formatting.

Proceeded to using VBA to automate the calculation of IBNR reserves for 30 different companies through use of  the calculator tool I built . Which directly inputted about 270 data points in specific cells in Excel to calculate each company’s specific IBNR reserve .

Made use of VBA for loops and If statements for the automation. 

Generated a clickable Macro that embedded the VBA function.
Proceeded to carry out data validation , which was a success.
